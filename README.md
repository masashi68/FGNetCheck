# FGNetCheck — 格闘ゲーム向け PC 設定チェック

日本語 | [English](README.en.md)

格闘ゲームのオンライン対戦や操作を不安定にする Windows の設定を見つけて、おすすめの値に直すツールです。

- **直す前の値を必ず保存します。** メニューの「元に戻す」で、いつでも戻せます。
- **効果がはっきりしない「最適化」は入れません。** 標準から外れた値や、省電力で通信や入力が途切れる設定を正すことが目的です。
- **セキュリティは下げません。** 他のツールが下げたセキュリティの設定は、見つけて案内します。

## 使い方

1. [Releases](../../releases) から `FGNetCheck-<版>.zip` をダウンロードし、右クリックして「すべて展開」を選びます。
2. `FGNetCheck.bat` をダブルクリックします。管理者の確認には「はい」を押します。
3. メニューの番号を入れて Enter を押します。まず `1`（診断）を実行すると、何も変えずに今の状態を確かめられます。

詳しくは、zip に入っている `使い方.txt` を読んでください。

表示が英語の版は `FGNetCheck-<版>-en.zip` です。表示の言葉が違うだけで、中身は同じツールです。

## できること

| メニュー | 内容 |
|---|---|
| 1. 診断する | 設定とおすすめの差、手作業で直してほしいこと、起動とセキュリティの状態を表示します。何も変えません |
| 2. おすすめ設定 | 次の設定を変えます。変える前の値は `backup` フォルダに JSON で保存します |
| 3. 元に戻す | 保存した値に戻します |
| 4. 通信を測る | ルーターと 1.1.1.1 までの遅延・ゆらぎ・跳ね・ロスを同時に測り、`measure_log.txt` に記録します。P2P 対戦のつながりやすさ（NAT の型、二重ルーター）も確かめます |

### 4 の測り方

| 測り方 | 内容 |
|---|---|
| 短い測定 | 約 20 秒。設定の前後を比べるのに使います |
| 長い測定 | 約 3 分。数十秒おきに起きる跳ね（Wi-Fi の周辺スキャンなど）を見つけます |

測定では、次の相手に接続します。診断・おすすめ設定・元に戻すは、外部に接続しません。

- `1.1.1.1`（ping）
- `stun.l.google.com`、`stun.cloudflare.com`（NAT の型の確認。UDP を 1 往復ずつ）

### 2 で変えるもの

- ネットワーク アダプターの省電力（省電力イーサネット、Green Ethernet など）をオフにする
- 他のツールが変えた通信の設定を Windows の既定に戻す（LSO、RSC、輻輳制御 CUBIC、初回の再送待ち）。これらは TCP の設定で、UDP を使う対戦中の遅延は変わりません。ダウンロードなどの通信を元の状態に戻すための項目です
- 電源接続時の電源プランを調整する（PCI Express と USB の省電力をオフ、CPU の最大の状態を 100%、ブーストをオン、Wi-Fi の省電力をオフ）
- ゲームモードをオンにし、マウスの「ポインターの精度を高める」をオフにする
- 最適化ツールが `GraphicsDrivers` に残した値を消す（GPU の自動復旧を止める `TdrLevel` などを含む）

### 診断だけで、変えないもの

- 対戦ゲーム（Steam のゲームと Fightcade）の通信をブロックしているファイアウォールの規則
- Wi-Fi の電波、有線 LAN のリンク速度と通信エラー、VPN などを経由していないか
- ドライバーの既定と違うアダプター設定、Windows Update の配信の最適化
- メーカー製の通信制御ソフト（Killer など）、GPU ドライバーの古さ、リフレッシュレート
- ウィンドウ表示のゲームの最適化、ドライブの最適化、SysMain、メモリ、ディスクの空き容量
- 起動設定のタイマー、Exploit Protection、VBS とメモリ整合性、Defender、UAC、ファイアウォール、SmartScreen

## 動作環境

- Windows 10 / 11（Windows PowerShell 5.1）
- 会社や学校の管理下にあり、PowerShell が制限されている PC では動きません。動かない場合は、起動したときにそう表示して終了します。

## 開発

- 本体は `src/FGNetCheck.ps1` です。`powershell -ExecutionPolicy Bypass -File src\FGNetCheck.ps1` でそのまま実行できます。
- `build.ps1` を実行すると、本体を埋め込んだ配布用の `dist/FGNetCheck.bat`（日本語版）と `dist/en/FGNetCheck.bat`（英語版）ができます。bat は一時ファイルを作らず、自分自身の後半を PowerShell のスクリプトとして実行します。
- 本体に書くのは日本語だけです。英語版は、ビルドのときに日本語の文字列を `lang/en.txt` の対訳で置き換えて作ります。訳が足りない、または使われなくなった訳が残っていると、ビルドが止まります。
